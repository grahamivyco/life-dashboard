# Life Dashboard

Graham's personal app: Today, Brain Dump, Goals & Ideas, Timeline, Finances, Jobs, Email, Clients, Housing and Events in one place.

- Live: https://grahamivyco.github.io/life-dashboard/
- Stack: React + Vite, Supabase (project `life-dashboard`, eu-west-3), GitHub Pages
- Deploys automatically on every push to `main`

## Run locally

```
npm install
npm run dev
```

## Phases

1. Web app shell (this)
2. Mac app (Tauri)
3. Brain Dump, Today, Goals & Ideas, Timeline
4. Finances, Jobs, Email, Clients, Housing, Events + Google Calendar sync
5. Scheduled sync tasks, ⌘K search, polish
6. Share pages with Ben
